# YOLO-tools

一批处理 YOLO 数据集的小脚本。零依赖框架，都是「选个文件夹 → 填个参数 → 跑」的单文件工具，解决标注前后最烦的那堆手工活。

2025 年 2 月集中写的，之后没再改。每个脚本头部有完整的文件名 / 功能 / 作者 / 日期注释。

---

## 数据清洗

删掉那些会让训练报错或白跑的东西。

| 脚本 | 作用 |
| --- | --- |
| `删除无json图片.py` | 删掉没有对应 labelme JSON 标注的图片（格式转换前的常见残留） |
| `删除无图片标签.py` | 反向清理：删掉找不到原图的标签文件 |
| `删除无标签图片.py` | 删掉没有标注文件的正样本图，避免被当成负样本训进去 |
| `删除空内容txt文件.py` | 清掉 0 字节的 txt，YOLO 会把它当空标注 |
| `移除错误编号的txt文件.py` | 清理类别编号超出 `nc` 范围的标注 |

## 数据整理

| 脚本 | 作用 |
| --- | --- |
| `分类高质量图片.py` | 按有效像素数把图片分成高/低质量两个文件夹，阈值自定。低质量图通常是糊的、逆光的、镜头脏的 |
| `分类高质量对应txt.py` | 配合上一个，标签文件跟着图片一起分 |
| `检测标签移动图片.py` | 把带特定类别标注的图片挑出来单独存，用于筛目标数据或剔除无关爬虫图 |
| `重命名数据集.py` | 批量重命名，统一编号 |
| `随机划分验证集.py` | 把 `train/` 按比例分一部分到 `val/`，jpg 和 txt 同步搬。每次训练重新划一次，防止验证集过拟合 |

## 数据生成

| 脚本 | 作用 |
| --- | --- |
| `拆分视频帧.py` | 视频抽帧成图，扩充素材 |
| `数据增强.py` | 旋转、加噪、水平/垂直翻转，成倍扩数据量；**标注框同步变换**，保证框还锁得住目标 |

## 模型导出

| 脚本 | 作用 |
| --- | --- |
| `To_onnx.py` | `.pt` → `.onnx`，部署用 |
| `model.yaml` | 模型结构定义 |

---

## 用法

直接跑，脚本会弹文件夹选择框或提示输入参数：

```bash
python 分类高质量图片.py
python 数据增强.py
```

依赖：`numpy`、`opencv-python`、`ultralytics`（仅 `To_onnx.py` 需要）。

---

## 注意

- 大部分脚本是**破坏性操作**（直接删文件）。第一次跑先拿小样本试，或者先备份数据集
- 目录结构默认 YOLO 标准布局：`images/` 与 `labels/` 平级，文件名同名不同后缀
- 这些脚本写于 2025 年初，`ultralytics` 的 API 后来有变动，`To_onnx.py` 可能需要按当前版本调整
